# Профиль СМИ: Setters Media (`setters`)

> Шаблон. Заполни эталонными абзацами из реальных публикаций. Можно держать в Memory MCP под ключом `media_profile:setters`.

## Тон в одной фразе
Современно, для молодой аудитории, маркетинг и брендинг.

## Стилистические правила
- Лексика комьюнити, англицизмы там, где они общеприняты в маркетинге.
- Допустима эмоциональная подача и личная позиция.

## Типичные жанры
Кейс, разбор тренда, мнение.
