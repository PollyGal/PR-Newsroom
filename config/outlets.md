# Справочник изданий — вес N (охват + релевантность аудитории)

Вес издания учитывает И охват, И релевантность аудитории.
Профильная площадка с точным попаданием в аудиторию ИИ-обучения
может весить выше крупного обобщённого СМИ. Ставится вручную.

## Ориентир для веса N (не жёсткая шкала)
- N 5 — топовые федеральные + профильные с точным попаданием
- N 4 — сильные отраслевые / авторитетные ниши
- N 3 — средние СМИ и заметные тематические площадки
- N 2 — небольшие, но релевантные издания и каналы
- N 1 — нишевые блоги, малые каналы
- N 0.5 — агрегаторы, релизоприёмники, нерелевантное

Издание не из списка → N = 1 (дефолт для неизвестного), пометить в выводе.
