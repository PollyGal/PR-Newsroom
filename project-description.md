# Валькирии — PR-ньюсрум

*Дашборд над мультиагентным PR-пайплайном: newsjacking → адаптация под СМИ → оценка эффективности*

---

## Название

**«Валькирии — PR-ньюсрум»** — единая витрина-дашборд, которая показывает работу трёх PR-агентов (Хильда, Сага, Фрейя) в одном окне.

## Проблема

PR-отдел Зерокодера ведёт несколько процессов вручную и в разных местах: ловит инфоповоды для оперативной реакции, переупаковывает один материал под разные СМИ с проверкой уникальности и оценивает медиаэффективность публикаций. Эти процессы живут в файлах, папках и почте — нет единой картины, приоритеты и статусы теряются, а эффект публикаций сложно наглядно показать руководству. Нужен один экран, где видно весь PR-конвейер: что горит, что готово к питчу и что в итоге сработало.

## Пользователь

PR-специалист и небольшая PR-команда Зерокодера. Шире — любой PR-отдел, который ловит инфоповоды, готовит материалы под несколько изданий и отчитывается за эффективность.

## Основная функция

Дашборд-витрина над тремя агентами, выстроенными в один конвейер.

**Что подаётся на вход:** медиаполе по заданным темам (beats) и исходные материалы компании (например, пресс-релизы).

**Что происходит внутри:**
- **Хильда** (newsjacking-скаут) сканирует источники, квалифицирует поводы по чек-листу из 6 критериев, присваивает приоритет (срочно сегодня / важно на неделе) и оформляет брифы. Бриф получает id, который служит тегом кампании.
- **Сага** (агент-адаптер) берёт бриф и готовит 4 стилистически разных версии под конкретные СМИ (Forbes Russia, РБК Компании, Инк, Setters Media), проверяя уникальность каждой через API text.ru.
- **Фрейя** (пайплайн PR Points) оценивает вышедшие публикации по методике Skyeng (PR Points = N × MQI), строит рейтинг Зерокодера против конкурентов и сворачивает эффект по релизу/кампании (привязка выходов к релизу через тег кампании).

**Что получается на выходе и попадает в дашборд:** лента поводов с приоритетом, карточки 4 версий с процентом уникальности и статусом, рейтинг публикаций по PR Points и эффект по кампаниям.

**Инструменты:** субагенты Claude Code (Sonnet и Haiku), Anthropic API, API text.ru, MCP-серверы (веб-поиск, Google Drive, Memory, почта).

## Формат результата

Единый веб-дашборд (витрина), который наглядно показывает три блока конвейера; готовые к питчу тексты под 4 СМИ с подтверждённой уникальностью; отчёт по PR Points с рейтингом и разбивкой эффекта по релизам.

## Минимальный функционал (MVP)

Дашборд показывает три блока на данных прогонов агентов: поводы с приоритетом (Хильда), 4 версии с уникальностью и статусом (Сага), рейтинг по PR Points и эффект по кампаниям (Фрейя). Для стабильной демонстрации есть демо-режим и демо-команда «Валькирии, демо-прогон по кампании <id>», которая проходит всю цепочку на заранее подготовленных данных без живых внешних вызовов. Связка Хильда → Сага запускается одной командой. Полные тексты публикаций хранятся локально, в репозиторий идут выдержки и итоговый отчёт (авторские права). Проект деплоится на Vercel / GitHub Pages и публикуется на GitHub с инструкцией запуска.

**Планы развития:** живой запуск агентов прямо из интерфейса; автонакопление статистики PR Points по неделям и динамика; второй сервис проверки уникальности как «второе мнение»; расширение списка СМИ.

## Технологии

- **Фронтенд и деплой:** статический дашборд на HTML/CSS/JS (один файл `index.html`, без сборки), веб-шрифты Google Fonts; деплой на Vercel или GitHub Pages как статика.
- **Агенты:** субагенты Claude Code (модели Sonnet и Haiku), оркестрация через `CLAUDE.md`, Anthropic API.
- **Расчёт:** детерминированный Python-скрипт (`calc_pr_points.py`) — арифметику PR Points делает код, а не модель.
- **Внешние сервисы:** API text.ru (проверка уникальности).
- **MCP:** веб-поиск (brave-search / tavily), fetch, Google Drive, Memory, time, Gmail.
- **Данные:** результаты агентов в файлах (брифы, `summary.json`, отчёт `pr-report.md`); дашборд читает их, в демо-режиме — встроенные данные.
- **Форматы ответов агентов:** структурированный JSON (разбор публикации, расчёт PR Points, метаданные версий, поле `campaign`).
