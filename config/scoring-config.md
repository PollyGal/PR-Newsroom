# Схема расчёта PR Points

Формула (адаптирована из методики Skyeng): **PR Points = N × MQI**
где MQI = Формат × Ключевые сообщения × Упоминание бренда

N (вес издания) — см. config/outlets.md.

## MQI критерий 1: Формат публикации
| Формат | Код | Коэффициент |
|---|---|---|
| Развёрнутый кейс о субъекте | case | 1.5 |
| Интервью / колонка / исследование | interview | 1.2 |
| Комментарий эксперта | comment | 0.5 |
| Упоминание вскользь | mention | 0.2 |

## MQI критерий 2: Ключевые сообщения
| Условие | Коэффициент |
|---|---|
| Сообщения раскрыты по смыслу | 1.0 |
| Не донесены | 0.3 |

## MQI критерий 3: Упоминание бренда
| Условие | Код | Коэффициент |
|---|---|---|
| Чёткое упоминание | clear | 1.0 |
| Смазанное | blurred | 0.5 |
| Не упомянут явно / не про субъект | none | 0.3 |

## Что упрощено относительно полной формулы Skyeng
Критерии «кто инициировал» и «новизна издания» НЕ учитываются —
они требуют данных из CRM/истории отношений со СМИ, а не из текста.
PR Points здесь — порядковая шкала (больше/меньше, динамика), не точное измерение.

ВАЖНО: эти коэффициенты синхронизированы со scripts/calc_pr_points.py.
При изменении правь оба места.
